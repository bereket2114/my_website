## Getting Started

To run this portfolio locally:

1. **Clone the repository**
   ```bash
   git clone https://github.com/bereket2114/my-professional-portfolio.git
   cd bereket_portfolio_website
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **View in browser**
   Open `http://localhost:5173` (or the port provided in your terminal).

## Build

To build the project for production, run:
```bash
npm run build
```
This executes the TypeScript compiler (`tsc -b`) and generates optimized static assets using Vite (`vite build`) in the `dist/` directory.
